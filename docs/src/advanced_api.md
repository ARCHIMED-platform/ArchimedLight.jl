# Advanced API Reference

This page lists non-exported docstrings used by advanced debugging, parity, and
research workflows. These names are available through qualified calls such as
`ArchimedLight.compute_sky(...)`, but they are not part of the exported stable
API for the `0.1.x` series.

Prefer the exported workflow built around `LightSimulation` and `run_light` for
application code.
